# 1 - A + B Problem

> [View the original problem](https://loj.ac/p/1)

---
### Description

Given $A$ and $B$, compute and print $A + B$.

### Input Format

One line with two integers $A$ and $B$, separated by a space.

### Output Format

One integer $A + B$.

### Example

```
1 2
```

```
3
```

### Limits

For $ 100\% $ of data, $ 1 \leq a, b \leq 10 ^ 6 $。
